# Soldadura e Reparação de PCBs

Durante a minha formação, desenvolvi competências práticas na montagem,
soldadura e reparação de placas de circuito impresso (PCB).

## Competências desenvolvidas

- Soldadura de componentes THT
- Soldadura de componentes SMD
- Dessoldadura e substituição de componentes
- Utilização de ferro de soldar
- Aplicação e controlo de estanho
- Identificação e correção de soldaduras deficientes
- Inspeção visual das soldaduras
- Manuseamento adequado de componentes eletrónicos

## Soldadura THT

Componentes THT (Through-Hole Technology), com inserção dos terminais
através dos furos da placa.

## Soldadura SMD

Componentes SMD (Surface-Mount Device), soldados diretamente na superfície
da placa de circuito impresso.
